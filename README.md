# УЭТ Карты 🚋

Пассажирское приложение с картой трамваев и троллейбусов Ульяновска. Маршруты, остановки и информация о движении — на экране телефона.

📲 [Скачать приложение для Android](https://github.com/gamedich/uetmap-passenger/releases/tag/v1.0.2-beta)  
🗺 [Открыть карту в браузере](https://uet-map.ru/)  
💬 [Новости и обратная связь](https://t.me/uet_maps)

Приложение пока в бета-тестировании. Офлайн-режим и работа на разных телефонах ещё проверяются.
