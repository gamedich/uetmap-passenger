# Пассажирское приложение УЭТ Карт

Исходники тестовой сборки 1.0.2-beta: приложение открывает `https://uet-map.ru/`. Локальные файлы предназначены для ограниченного офлайн-режима, который требует проверки на устройстве. Сертификаты HTTPS не обходятся; секретов и файлов админки в ресурсах нет.

Для локальной сборки нужен JDK 17, Android SDK 33 и Gradle 8.5: `gradle :app:assembleDebug`. Debug-сборка подписывается тестовым ключом Android и не обновит опубликованный APK. Для релиза нужен отдельный безопасный процесс подписи существующим ключом. Не добавляйте keystore и пароли в Git.

Репозиторий содержит только пассажирское приложение. Сервер карты, HR и закрытые данные сюда не включены.
